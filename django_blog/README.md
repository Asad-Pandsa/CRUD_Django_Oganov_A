# Django-блог

В приложении есть список статей и страница каждой статьи. Статьи можно
создавать, редактировать и удалять. Логика операций CRUD находится в соседней
папке `CRUD`. Поле `Blog.likes` хранит количество просмотров: при каждом
GET-запросе страницы статьи значение увеличивается на единицу.

После применения миграций в блоге появятся статьи о Винсенте ван Гоге,
Леонардо да Винчи и Микеланджело с фотографиями из папки `photo` рядом
с папкой `django_blog`.

## Запуск

Из этой папки выполните:

```powershell
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Список статей доступен по адресу `http://127.0.0.1:8000/`.
На странице списка доступны ссылки для создания, редактирования и удаления
статей.

## Тесты

```powershell
python manage.py test blog
```

Тесты проверяют страницы списка и статьи, операции CRUD, ответ 404 для
неизвестного идентификатора, начальное значение счетчика и его увеличение при
каждом открытии страницы.
